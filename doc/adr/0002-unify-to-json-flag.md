# 0002: エージェント向け --json フラグへの統一

- **ステータス**: Accepted (承認済)
- **決定者**: プロジェクトチーム
- **作成日**: 2026-07-20

## コンテキスト (Context)
主要なAIエージェント向けCLI設計原則（原則2：JSON First）では、構造化出力を求める方法として単一の `--json` ブールフラグの提供が強く推奨されている。従来の `-f / --format text|json` のパラメータ指定は、他のエージェント向けCLIと異なり、呼び出しの摩擦を増やしていた。

## 決定 (Decision)
1. 全てのデータ出力系コマンドから `-f/--format` オプションを廃止する。
2. `--json`（ブールフラグ、`-j`）を追加する。フラグ指定時はJSON出力、未指定時はデフォルトのテキスト出力とする。

## 影響 (Consequences)
- **メリット**: AIエージェントは `--json` または `-j` フラグを指定するだけで一貫してJSONを取得でき、引数設計が極めてシンプルになる。
- **デメリット**: 従来の `--format` 呼び出しを行うスクリプト等は動作しなくなる（破壊的変更）。しかし、プロジェクトが初期開発段階（feat/core）であるため、このタイミングでの完全移行が最も低コストである。
