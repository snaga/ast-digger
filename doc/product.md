# 製品概要 (product.md)

## 🌟 製品の目的
AIエージェントが大規模なコードベースを探索する際、ファイル全体を読み込むと発生するトークン（コンテキスト）の無駄遣いやノイズの混入を解決するために、ASTを高速かつ正確に解析できる **tree-sitter** を利用し、エージェントが必要な情報だけを「ピンポイント」かつ「構造的」に掘り出す（Digる）コマンドラインツールを提供すること。

具体的には、以下のメリットを提供する：
- **単一バイナリ配布**: ランタイムや仮想環境のセットアップなしに、コンパイル済みの単一実行ファイルとして配布・実行できるようにする。
- **起動時間の短縮**: インタプリタの起動やパッケージインポートのオーバーヘッドを排除し、CLI呼び出しごとのレイテンシを最小化する。
- **CI/コンテナ環境への親和性向上**: ランタイムの事前インストールが難しい実行環境（軽量コンテナ、サンドボックス等）でも動作させられるようにする。

## 🎯 ターゲットユーザー
- **AIエージェント** (例: Antigravity などの開発支援エージェント)
- **AIエージェントを活用して自律的なコード変更を行う開発者**
- **ランタイムのインストールに依存できない実行環境でツールを利用したい運用者**（CI/CDパイプライン、軽量コンテナ、社内サンドボックス等）

## ✨ 主要機能 (Core Features)
1. **コードのアウトライン抽出 (Skeleton / Outline Extraction)**:
   - 実装の本体を除外し、クラス定義、メソッド/関数定義、docstring/コメント、引数・戻り値の型などの構造（スケルトンコード）だけを抽出してLLMに提示する。
2. **ピンポイントコード抽出 (Targeted Symbol Extraction)**:
   - 指定したシンボル（例: `file_path::ClassName.method_name`）の実装コードだけをASTノードからピンポイントで抽出する。
3. **呼び出し関係と参照の探索 (Call Graph & Reference Tracer)**:
   - 指定したシンボルの呼び出し元（Callers：参照箇所）や、呼び出し先（Callees：定義場所）を構文レベルで探索・追跡する。
4. **インポート定義場所の解決 (Import Definition Resolver)**:
   - 対象のシンボルが依存しているローカルモジュールのインポート文を自動で解析し、その定義場所（ファイル・行番号）を特定する。（将来機能拡張として、依存コード本文の自動追跡抽出 `--follow-imports` を計画）。
5. **フォルダ全体の構造化アウトライン (Directory/Module Outline)**:
   - フォルダ以下のファイル構成と、各ファイルに定義されている公開シンボルの一覧をコンパクトなツリー形式で出力する。SQLiteデータベースを活用して変更があったファイルのみ差分スキャン（インクレメンタルスキャン）を行う。
6. **エージェント運用品質の強化機能**:
   - `agent-context` の完全性、出力上限制御、エラー候補提示、終了コードタクソノミー、`SKILL.md`、`--json` 統一を標準搭載する。
7. **SQL・CTEデータフロー構造解析 (SQL & CTE Flow Analyzer - Snowflake Dialect)**:
   - 数千行に及ぶ巨大なバッチSQL（Snowflake/DWH）を構文解析し、CTE（Common Table Expression）の定義階層、DAG（依存グラフ）、サブクエリ添字（`subquery[0]`）、および参照テーブルを抽出し、リファクタリング対象のCTEとその上流依存のみをピンポイントで取得可能にする。

## 🚀 ビジネス目標 / ゴール
1. **高い実行パフォーマンス**: 起動時間・実行時間・メモリ使用量を最小限に抑える。
2. **配布の簡素化**: `go build` により、依存関係のない単一バイナリとして配布できるようにする。CGO依存を許容する方針決定（[`tech.md`](./tech.md) 参照）に伴い、Windows/macOS/Linux向けバイナリはクロスコンパイルではなく各プラットフォーム上でのネイティブビルドによって生成する。
3. LLMに読み込ませる不要なコードノイズを排除し、推論の正確性を最大化する。

## ⚠️ 制約事項 / スコープ外
- **ターゲット言語のサポートスコープ**: **Python**, **TypeScript**, **Go**, **Java**, **JavaScript**, **Rust**, **Markdown**, **SQL**（メイン方言: Snowflake SQL、および標準SQL）コード・ドキュメントの解析をサポートする。
- **軽量・高速性優先**: 言語サーバー（LSP）のような完璧な型推論や仮想環境の完全な解決は行わず、tree-sitterによる構文（AST）ベースの超高速・軽量な解析を重視する。
- **MCPサーバー機能はスコープ外**: 将来的な拡張としてのMCPサーバー実装は、現時点のスコープには含めない（[`tech.md`](./tech.md) 参照）。
